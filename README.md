# Scorigami: Test Cricket (Men's)

Every total a men's Test innings has finished on, from 0 to 999: which have happened, how often, and how those innings ended.

**Site:** https://buckle-badger.github.io/test-cricket-scorigami/

The page rebuilds itself each morning and picks up new Tests as they're added to Cricsheet.

## Sources

- **Scorigami** is Jon Bois's idea, from his 2016 SB Nation video "Chart Party: Scorigami" on NFL scores.
- **Match data to March 2024:** Bhuvanesh Prasad's [Test Cricket Matches Dataset (1877–2024)](https://www.kaggle.com/datasets/bhuvaneshprasad/test-matches-dataset-1877-2023) on Kaggle, used under the Apache License 2.0 (copy in `data/LICENSE-kaggle-dataset.txt`).
- **Match data since 2001 and every new Test:** [Cricsheet](https://cricsheet.org), used under the [Open Data Commons Attribution License](https://opendatacommons.org/licenses/by/1-0/).
- **Innings endings** checked by hand against scorecards on [ESPNcricinfo](https://www.espncricinfo.com).

Corrections and feedback are welcome on X: [@bucklebadger](https://x.com/bucklebadger).
